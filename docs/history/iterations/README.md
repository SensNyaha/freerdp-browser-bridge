# Архив проверок и итераций

444 прежних отчёта объединены в 10 томов вместо отдельных файлов.
Сохранены исходный текст, даты, команды, результаты, ограничения и ссылки;
добавлены явные якоря итераций/разделов. [Индекс исходных SHA-256](index.json)
содержит соответствие прежнего пути новому тому и неизменяемому source commit.
Это исторические доказательства, а не текущая инструкция установки.

Отчёты, вернувшиеся из незавершённых feature-веток после первоначальной
очистки, добавляются в те же тома. Для них поле `additionalReports` индекса
содержит собственный source commit и исходный SHA-256; исходная группа из
444 записей сохраняется. Так восстановлен [отчёт 406](401-450.md#iteration-406)
ветки управляемых дисков.
