# Iteration 406 — managed-drive filesystem foundation

2026-10-21. SPECIFICATION §2.8 / SECURITY §6, isolated on
`feature/managed-drives` from `master` `4e3ec09`. This is an internal foundation,
not completion or advertisement of managed drives. No REST, RDPDR, quota or
session lifetime integration is installed yet; the complete feature stays on
its branch until those requirements and real remote CRUD acceptance pass.

`SafeRoot` takes only a trusted already-private root. Relative UTF-8 paths are
bounded before allocation and reject traversal, absolute/Windows namespace
forms, alternate streams, malformed UTF-8 and ambiguous DOS names. Reads/writes
use owned OS handles, explicit offsets and a 64 KiB operation maximum. Existing
regular files must have one link. Read-only file handles reject write/resize.
Public statuses contain no OS messages or paths. Byte quotas remain a required
